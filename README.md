# Training Log

A preseason training tracker for Valley Baseball players. Each player installs it on their own phone; all data stays on that phone.

## What it does
- Log lifts, plyometrics, core, arm care, cardio, and sprints from a built-in exercise library (players can add custom exercises).
- Suggested sets for every exercise: target weights for main lifts from the player's max on a 4-week cycle, and "beat last time" progressions for everything else.
- Estimates maxes from a set of 1 to 10 reps and offers to raise the max when logged sets show improvement.
- Rest timer, personal records, progress charts, and a weekly workout goal with streaks.
- Weekly and monthly reports players can share with coaches as an image or text. Workouts logged more than a day late are marked.
- Coaches can build a routine and share it as a link; players tap the link to add it.

## Updating
Upload the new `index.html`, then change `VERSION` in `sw.js` (for example `traininglog-v2`). Players open the app twice to load the update. Player data is not affected.
